# Sombra

Gatito niño negro en pixel art retro. Diseño aprobado: ojos blancos rectangulares y borde naranja. Nombre provisional: Sombra.

Incluye fuentes generadas, revisiones rechazadas, nueve estados animados, dieciséis miradas, PNG transparente v2, previsualizaciones y validaciones.

PNG final: final/spritesheet-extended.png. Validación estructural y de calidad aprobadas. Las miradas diagonales próximas a vertical tienen un componente lateral sutil.
